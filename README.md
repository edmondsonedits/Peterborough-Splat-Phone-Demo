# Peterborough Gaussian Splat Phone Demo

Four-street loop: touch arrows move, drag to look, Auto-drive follows the closed route at source-camera height. Open in landscape orientation.

Initial model transfer: about189MB; all12 sections load before driving. Requires WebGL2 and a capable phone. Actual physical-phone performance remains unverified.

Reduced-detail preview:1,820,455 splats with enlarged footprints for coverage. The full-quality reconstruction remains local. Soft foliage and vehicle ghosting remain. No truck physics or collision geometry.
